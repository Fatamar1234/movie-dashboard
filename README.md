# MovieLens Dashboard

Streamlit dashboard for the CUNY Tech Prep Week 4 MovieLens ratings file.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Push this repo to a **public** GitHub repository, then on [Streamlit Community Cloud](https://share.streamlit.io) select the repo, `main` branch, and `app.py`.
